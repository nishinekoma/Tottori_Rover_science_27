# 【サイエンス班】制御プログラム仕様書 (Pico W側)

## 1. 全体シーケンスフロー
```text
[Pi 5]                   [Pico W (main.py)]
  |                              |
  |--- "START\n" (UART受信) ---->| 待機解除・シーケンス開始
  |                              | 超音波測距 (distance.py)
  |<-- ログ / 進捗通知 (随時) ---| アーム展開 (motor.py)
  |<-- [LOG]CSVデータ (随時) ----| 土壌温度収束測定 (temperature.py)
  |                              | アーム格納・巻き戻し (motor.py)
  |                              | ログファイル保存 (log_result.csv)
  |<-- "SEQUENCE_FINISHED" ------| 完了通知送信（エラー時は SEQUENCE_ERROR）
  |    (または ERROR)            | 再び待機状態へ復帰
```

## 2. ファイル別仕様

### main.py（統括・通信・ロガー）
* **役割**: 全体シーケンス制御、Pi 5とのUART通信ハンドリング、全イベントの記録。
* **通信設定**: UART1 (TX: GP4 / RX: GP5), 115200 bps。
* **トリガー**: `START\n` 受信でシーケンス開始。
* **ロガー**: 
  * Pico内ストレージへ `log_result.csv`（UTF-8 BOM付き）を保存・追記。
  * Pi 5へ `[LOG]` プレフィックス付きで同一CSV行をリアルタイム送信。
* **フェイルセーフ**:
  * 途中で例外が発生した場合でも、`finally` 節でアームの緊急巻き戻しを試行。
  * 終了時は成否に応じ `SEQUENCE_FINISHED` または `SEQUENCE_ERROR: <理由>` を必ず送信。

### distance.py（超音波測距）
* **役割**: 地面までの垂直距離の計測。
* **使用ピン**: Trig: GP14 (Pin 19), Echo: GP15 (Pin 20 / 分圧経由)。
* **仕様**:
  * `get_distance()`: 単発測定（タイムアウト 30ms）。
  * `get_stable_distance(samples=5)`: 50ms間隔で5回測定し、有効値の中央/平均を算出。全測定失敗時は `None` を返却。

### motor.py（アーム昇降・PCA9685制御）
* **役割**: DCモーター駆動による測定アームの展開・格納。
* **使用ピン/バス**: I2C0 (SDA: GP0, SCL: GP1), PCA9685 アドレス `0x40`, 駆動CH: 0 (50Hz)。
* **パラメータ**: 駆動速度定数 `12.4 cm/s`。
* **仕様**:
  * `move_arm_by_distance()`: 
    * 移動量計算式: `実移動量(cm) = (測定距離 + 予備8.0cm) - 初期突出9.0cm`
    * 移動量に応じた時間だけ右回転駆動。実際に動かした距離(cm)を返却。
  * `retract_arm_simple()`: 展開した実移動量(cm)分だけ左回転駆動し、初期位置へ復元。

### temperature.py（土壌温度測定・収束判定）
* **役割**: DS18B20による土壌温度の取得と、熱平衡（収束）の判定。
* **使用ピン**: 1-Wire DATA: GP16 (Pin 21, プルアップ抵抗接続)。
* **仕様**:
  * `measure_until_stable()`:
    * **初期マスク期間**: 開始後 **10秒間** は過渡期として収束判定を無視。
    * **収束判定**: 直近 **10秒間** の測定データにおける変動幅（最大値 − 最小値）が **0.01℃ 以内** に収まった時点で測定完了・温度確定。
    * **タイムアウト**: 180秒経過でタイムアウト（最新値を返却）。
    * **コールバック**: 1回の測定（約750ms変換＋待機）ごとに `log_func` を経由してリアルタイムログを出力。
